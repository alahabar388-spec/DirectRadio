# Wi-Fi Direct test guide — milestone 0.2.0

## Preconditions
- Оба телефона поддерживают Wi-Fi Direct.
- Wi-Fi включён на обоих телефонах.
- DirectRadio получил разрешение «Устройства поблизости».
- На некоторых устройствах Android 8–12 требуется включить службы геолокации для поиска.

## Procedure
1. Установить одинаковый debug APK на оба телефона.
2. Запустить DirectRadio на обоих устройствах.
3. Нажать «Найти устройства» на обоих телефонах.
4. Дождаться появления второго телефона в списке.
5. На телефоне A нажать «Связать» напротив телефона B.
6. Подтвердить системный запрос Android, если он появится.
7. Проверить, что на обоих телефонах отображается сформированное соединение.

## Record
- Модель и версия Android каждого телефона.
- Видят ли устройства друг друга.
- Успешен ли запрос соединения.
- Сохраняется ли связь при выключенном экране (фоновый режим пока не реализован).
- Точный текст ошибки, если она появилась.

## Ограничения
На этом этапе реализовано только обнаружение Wi-Fi Direct и формирование P2P-группы. Кнопка PTT демонстрационная и не передаёт аудио. Mesh, прикладная аутентификация и сквозное шифрование отсутствуют. Не использовать прототип для чувствительных переговоров.
